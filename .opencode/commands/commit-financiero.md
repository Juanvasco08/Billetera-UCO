# Comando: Commit Financiero

## Pasos
1. Revisa qué clases de Java o archivos de configuración cambiaron.
2. Asegúrate de incluir solo cambios relacionados con un solo módulo (`cliente`, `cuenta`, `opencode`).
3. Ejecuta `git commit -m "tipo(modulo): explicacion"`.
