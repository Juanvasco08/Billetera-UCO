# Skill: Flujo Git Billetera

## Pasos de Integración
1. Crear la rama `development` si no existe.
2. Realizar avances progresivos guardando un commit por clase Java o módulo.
3. Validar el funcionamiento en `Main.java`.
4. Fusionar los cambios hacia la rama `main` al finalizar cada hito del proyecto.
